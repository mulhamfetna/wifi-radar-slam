# Revised manuscript (Elsevier `elsarticle`)

Supersedes the IEEE Access draft in `../` (kept as the record of that submission). Built around
the corrected results in `../../docs/results-corrected.md`.

| File | Purpose |
|---|---|
| `main.tex` / `main.pdf` | Manuscript |
| `refs.bib` | Bibliography (the Access bibliography plus the references new to this version) |
| `figures/` | Generated by `experiments/make_corrected_figures.py` (do not edit by hand) |
| `highlights.txt` | Highlights (≤ 85 characters each) |
| `cover-letter.md` | Cover letter, including the disclosure of the earlier drafts and corrections |
| `elsarticle.cls`, `elsarticle-num.bst` | Elsevier class (CTAN, generated from `elsarticle.ins`) |

Build:

```sh
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Every number in `main.tex` comes from `results/corrected_eval.json`,
`results/robustness_corrected.json` or `results/lidar_noisy_odom_geo.json`. After any results
change, regenerate the figures and re-check the tables against those files.
